## Project scope

The project analyzes a same-user same-item e-commerce funnel, heuristic session paths, fixed-window time/category comparisons, and rule-based user segmentation with short-window validation.

Raw data is not committed because it is multi-gigabyte. See the final GitHub README for the data source, reproduction scripts, output files, and limitations.
